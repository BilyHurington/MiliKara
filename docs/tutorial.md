# MiliKara 使用教程

本教程用 赤城みりあ（CV：黒沢ともよ）的「わたぐも」演唱视频演示，从放入视频到拿到带字幕的卡拉OK视频。安装见 [README](../README.md)，脚本调用见 [HTTP API](api.md)。

## 1. 启动

```bash
.venv/bin/milikara serve
```

然后在浏览器打开 `http://127.0.0.1:8765`。默认是**极简模式**；右上角可以在极简模式和**详细模式**之间切换。项目默认保存在 `~/.kara_align/projects`（`--root <目录>` 可以改）。

## 2. 极简模式：一键出片

### 2.1 做一首

<p align="center">
  <img src="images/simple-form.png" alt="极简模式的表单：模式、视频、歌词链接、字幕与视频" width="640">
  <br>
  <sub>极简模式的表单：模式、视频、歌词链接、字幕与视频</sub>
</p>

1. **模式**：歌词带时间（LRC，音乐平台的歌词都带）时选 **LRC 增强**，长前奏、间奏、重复的副歌更稳；只有文字时选**普通**。歌词没有时间时会自动改用普通模式。
2. **视频或音频**：
   - **视频**：字幕烧录在视频自己的画面上。也可以只放音频：歌词用的是网易云 / QQ 音乐链接时，自动取歌曲封面做背景（封面模糊后铺满画面，封面本身在上方居中，下方稍暗留给歌词）；粘贴的歌词没有封面，画面是纯黑。
   - **音频 + 背景**：放入音频，再放一张背景图片，或一段背景视频（循环播放，不用它的声音）。效果等于先用音频和背景合成视频，再加字幕。输出画面按背景的比例，长边 1920。背景在添加任务后保留，连续做几首可以一直用。
3. **歌词**：粘贴网易云 / QQ 音乐的**歌曲链接**（分享文字也行），会自动获取歌词、翻译和歌名歌手；也可以直接粘贴 LRC 或纯文本歌词，再填上歌曲名。
4. **字幕与视频**：
   - 配色：**模版配色**选朴素或荧光，再选一两个主题色，其余颜色自动搭配。也可以用**保存的预设**，或**设置里的样式**。
   - 开关：显示翻译；开头和结尾显示歌曲信息；注音用平假名、片假名还是罗马音，是否只标汉字；**特效**（唱到每个字时的效果，如星光、花瓣，或者无）单独选择，不受配色模版影响；**倒计时**：第一句前、间奏后是否在开唱前显示几个逐个消失的圆点。
   - 字幕默认比实际演唱**提前 150 ms** 显示（以所选样式为准，这里会写出实际数值），扫光看起来正好在唱；想改的话在详细模式“字幕样式 → 时间”里调整。
   - 视频声音：原声、降低人声（可以调人声保留的比例），或无声。
   - 右边的示意图会跟着改。这些选择会自动记住，下一首从同样的设置开始。

点 **开始制作**。任务加入后立刻读取视频和歌词；各种设置在添加时就固定到这个任务上，之后改设置不影响已经排队的任务。

### 2.2 确认第一句从哪里开始唱

<p align="center">
  <img src="images/calibrate-dialog.png" alt="确认开头位置：在波形上标出第一句开始唱的位置" width="720">
  <br>
  <sub>确认开头位置：在波形上标出第一句开始唱的位置</sub>
</p>

视频的声音和歌词里的时间经常差一段：视频有片头，或歌词是别的版本的时间。LRC 模式下，任务读完视频和歌词后会弹出这个对话框：

- 竖线是**标记**，虚线是**歌词里写的时间**。在波形上点击就能移动标记；也可以直接输入时间，或用 ±10 / ±100 ms 微调。键盘：空格从标记处播放 / 停止，← → 微调 10 ms，按住 Shift 为 100 ms。
- **从标记处播放** 和 **标记前 2 秒开始** 用来听第一句是不是从这里开始；**试听中间一句** 按当前偏移播放歌曲中间的一句，确认整首都对得上。
- 确认后，所有歌词按同样的偏移对齐，其余步骤全部自动完成。
- 不想标，可以在设置里把“歌词开头对齐”改成**自动检测**：人声分离后自动找出偏移，只有没把握时才会问你。

### 2.3 AI 注音（手动网页聊天）

<p align="center">
  <img src="images/readings-dialog.png" alt="AI 注音：复制提示词，粘贴 AI 的回复" width="720">
  <br>
  <sub>AI 注音：复制提示词，粘贴 AI 的回复</sub>
</p>

读音越准，对齐越准。AI 注音选的是 **手动（网页聊天）** 时，确认开头位置后会接着弹出这个对话框：

1. 点 **复制提示词**，粘贴到任意 AI 聊天网页（Claude、ChatGPT、Gemini、DeepSeek……）发送。
2. 把 AI 的完整回复粘贴回来，点 **提交并继续**。

回复会先校验，只采用通过校验的行，其余行保留规则读音。回复完全不能用时，对话框会说明原因，任务继续等待。也可以选 **跳过（用规则读音）**。

如果设置里选的是 Claude Code、Codex 或 API，这一步会自动完成，不会弹出对话框。

### 2.4 任务列表

<p align="center">
  <img src="images/simple-tasks.png" alt="任务列表：一个在等待确认，一个已经完成" width="760">
  <br>
  <sub>任务列表：一个在等待确认，一个已经完成</sub>
</p>

- 每个任务显示它的步骤：导入视频 → 获取歌词 → 确认偏移 → AI 注音 → 人声分离 → 对齐 → 生成视频。步骤后面有结果，比如“42 行 · 翻译 42 行”“419 个发音单元”。
- 列表只显示最近的 5 个任务（还没完成的总会显示），更早的点 **显示更早的 N 个任务**。完成的任务收起了处理步骤和说明，点 **处理详情** 展开；需要看一眼的“建议检查”始终显示。
- 在等你的任务会有黄色提示，点里面的按钮打开对应的对话框。等待中的任务不占队列，后面的任务照常进行。
- 任务按顺序一个一个处理。完成后点 **下载视频**；点 **详细模式** 或任务名，可以打开这个项目继续调整。
- 对齐后如果有值得看一眼的地方，任务下方会提示“有 N 处建议检查”：点它会在详细模式里打开“人工检查”的 **有问题** 标签页。
- 失败或取消的任务可以 **重试**，已完成的步骤不会重做。失败时会显示可能的原因和解决办法；**复制诊断信息** 把版本、系统、显卡、ffmpeg 和出错经过复制下来，反馈问题时直接粘贴（不含 API Key，用户名已隐去）。

## 3. 设置

左上角的 **设置** 页里是所有任务共用的选项。修改立即保存，只影响之后添加的任务。左边的菜单分成 AI 注音、人声分离、开头对齐、字幕样式、输出视频、存储空间、更新与反馈，一次只显示一项（窄屏时菜单在上方），下次打开还停在上次看的那一项。

<p align="center">
  <img src="images/settings-ai.png" alt="AI 注音：开关，打开后四选一" width="720">
  <br>
  <sub>AI 注音：开关，打开后四选一</sub>
</p>

- **AI 注音**：先打开“使用 AI 注音”，再选一种方式：
  - **手动（网页聊天）**：不用安装，也不用 API Key。
  - **Claude Code / Codex**：使用已登录的命令行工具，可以点“测试连接”。“运行位置”默认 **自动**，按顺序找：
    1. 命令行里装的（PATH）；
    2. 桌面应用自带的：Claude 桌面版的 Code 功能、ChatGPT / Codex 桌面版都自带一份；
    3. Windows 上 WSL 里装的（会加载你的登录 shell，用 nvm 装的也能找到）。

    也可以在下拉框里指定用哪一份，或选 **自定义路径** 填写程序位置（Windows 上以 `/` 开头的路径在 WSL 里运行）。
  - **OpenAI 兼容 API**：填入接口地址、模型和 API Key，也可以测试连接。

  使用 AI 时，歌词会发送给你选择的服务，音频不会发送。
- **人声分离**：开关、模型（默认 MelBand RoFormer）、运行设备。分离后对齐更准，也才能生成“降低人声”的视频；它是最耗时的一步，GPU 或 Apple 芯片上约 1–3 分钟。

<p align="center">
  <img src="images/settings-calibration.png" alt="歌词开头对齐：手动标记第一句或自动检测" width="720">
  <br>
  <sub>歌词开头对齐：手动标记第一句或自动检测</sub>
</p>

- **歌词开头对齐**：手动标记第一句最准；自动检测不需要你操作，没把握时仍会请你确认。
- **字幕样式**：“设置里的样式”的完整样式面板，与详细模式相同，也可以复制某个项目调好的样式。面板上方是分类（配色、歌词、注音、翻译、歌曲信息、布局、时间、特效），一次显示一类，鼠标停在分类上可以看到它现在的设置。
- **输出视频**：是否自动生成视频、画质，以及是否使用显卡编码。
- **存储空间**：一共占了多少、磁盘还剩多少，点 **查看和清理** 管理（见“常见问题”）。
- **更新与反馈**：检查新版本，复制诊断信息。

## 4. 详细模式：逐步检查和微调

左边是工作流程。每一步都可以回头修改；改了歌词、读音或校准之后，对齐结果会标为过期，重新对齐即可。底部是所有页面共用的播放器和波形：点击定位，拖动选出循环区间，滚轮缩放。

### 音频与歌词

<p align="center">
  <img src="images/detail-input.png" alt="音频与歌词：原曲、人声和伴奏分轨" width="860">
  <br>
  <sub>音频与歌词：原曲、人声和伴奏分轨</sub>
</p>

上传原曲（音频或视频，视频会无损提取音轨并保留画面），粘贴或上传歌词，也可以用音乐链接获取歌词。解析后先预览，确认了才会应用。已有的人声 / 伴奏分轨也可以在这里导入，导入时会检查它们和原曲是否同步。

### 注音与分离

<p align="center">
  <img src="images/detail-enhance.png" alt="注音与分离：每个片段的读音和发音单元" width="860">
  <br>
  <sub>注音与分离：每个片段的读音和发音单元</sub>
</p>

每个词显示它的读音，以及读音切成的发音单元（一拍一个）。点片段就能修改读音。AI 注音可以一键完成（需要设置 CLI 或 API），也可以复制提示词、粘贴回复：校验后先预览差异，再选择要应用的行。人声分离也在这一页。

### 首音校准

<p align="center">
  <img src="images/detail-calibrate.png" alt="首音校准：在波形上标记第一个实际发音" width="860">
  <br>
  <sub>首音校准：在波形上标记第一个实际发音</sub>
</p>

与极简模式的“确认开头位置”是同一件事。选一句歌词（默认第一句），在它实际开始唱的地方标记（播放时按 M 在当前位置标记），程序据此算出全局偏移。**自动匹配** 会先试对齐一次，取大多数行一致的偏移作为建议，需要你试听后再应用。还可以用中间或结尾的一句检查偏移是否一致。

### 对齐 → 人工检查

<p align="center">
  <img src="images/detail-review.png" alt="人工检查：统计、每行的时间、波形上的发音单元" width="860">
  <br>
  <sub>人工检查：统计、每行的时间、波形上的发音单元</sub>
</p>

在“对齐”页运行模型（有人声分轨时默认用人声）。“人工检查”页：

- 上方是统计：发音单元数、没对上的、提示（可能需要看看的地方）、人工修改、覆盖率。
- 左边是逐行列表，**有问题** 标签页只列出有提示的行。
- 右边是选中行的每个单元，可以输入时间，也可以在波形上拖动两端修改。一整行都偏了的话，用上方的 **整行**：改行首就整行平移（也可以点 ±10 / ±100 ms），改行尾就按比例伸缩，一步就能撤销；只偏了几个字的话，在表格或波形上先点一个单元，再 Shift 点另一个（选中中间一段，可以跨行）或 ⌘ / Ctrl 点（逐个加选），然后在波形上拖动选区整体移动、拖两端按比例伸缩，碰到前后没选中的单元会停住。改过的单元会锁定，重新对齐也不会覆盖。可以 **循环试听整行**，或对这一行 **局部重跑**（得到候选结果，需要确认后才采用）。
- 快捷键：Space 播放 / 暂停，L 开关循环，↑ / ↓ 选择单元，Enter 播放，⌘Z / Ctrl+Z 撤销。

### 演唱者（多人演唱时）

可选的一步，单人演唱的歌曲不需要。多人演唱时，可以给每位歌手不同的字幕颜色：

1. 在右边 **添加演唱者**（人数不限），给每人选一个主色，名字可填可不填。未唱、描边、荧光的颜色会自动搭配，展开后也可以逐项修改。每人右边的小方块是 **快捷键**：新添加的演唱者自动用还没被占用的第一个键（按 1–9、A–Z 的顺序；L 和 P 已用于循环和试听）；点一下方块再按新的键就能修改，这个键已经给了别人时两人互换，按 Backspace 清空。
2. 边听边找位置：按 Space 播放，歌词上会有一条竖线跟着正在唱的字走，正在唱的那一行会高亮并自动滚到可见的地方（可以关掉“跟随播放”）；双击歌词就从那里开始播放。
   在左边的歌词里选中要指定的部分：点 **行号** 选整行（Shift 点选一段、⌘ / Ctrl 点逐行加选）；也可以在歌词上 **按住拖动**，按词选择，可以一直拖到下面几行（按住 ⌘ / Ctrl 拖动是追加）。
3. 按演唱者的 **快捷键** 指定是谁唱的（上方的按钮里也标着每人的键，点按钮也可以）。几个人一起唱：先按 1，再按 **+** 和 2，就是 1+2（也可以在上方输入“1+2”）。按 **0** 清除（整行回到默认配色，选中的几个词回到这一行的设定）。每次指定都能用 ⌘Z / Ctrl+Z 撤销。
4. 常一起唱的几个人可以存成 **组合快捷键**：按完 1+2 后点上方的“把 1+2 存到 3”（或在右边“组合快捷键”里添加），以后按 3 就是 1+2。组合同样自动用第一个空着的键，也可以点它的方块修改。每个组合还可以选自己的效果（上下 / 左右，分色 / 渐变），不选就跟随下面的默认设置：这几个人一起唱的部分都按这个组合的效果显示（顺序不同也算），比如三人合唱用渐变、两人对唱用上下分色。
5. 同一组歌手的其他歌曲可以用 **演唱者预设**：右边“演唱者”卡片最上面点 **存为预设**，会保存名字、颜色、快捷键、组合（包括各自的效果）、默认的一起唱效果和注音设置；在另一首歌里选中预设点 **载入**。已经指定过的部分按名字对应到预设里的人（没有名字的按编号），预设里没有、但歌词里用到的人会保留在最后，不会丢。

几个人一起唱的部分按右边的默认设置显示（组合有自己效果的除外），可以 **分色** 或 **渐变**：**上下** 是每个字上下分开（1+2 就是上半 1 号、下半 2 号）；**左右** 是一起唱的一整段从左到右分开（左边 1 号、右边 2 号）。**注音** 的颜色可以选：**自动**（上下分色时注音字小，整个用第一位的颜色；左右时跟着所在的位置）、**跟着分色**（和歌词一样分）、**第一位的颜色**（不分色）。翻译的文字保持自己的颜色（默认白色，容易看清）；开着荧光边缘时，翻译的荧光跟着这一行的演唱者变色，几个人唱的行从左到右渐变（字幕样式 → 翻译 →“荧光跟随这一句的演唱者”，可以关掉）。空格不算谁唱的：夹在同一段里的空格跟着这一段，两段之间的空格不上色。右上的预览就是选中部分唱到时的画面，与烧录完全一样。

歌词里如果写着演唱者（例如网易云歌词里的“A：”“（XX）”“【成员名】”），页面顶部会提示 **识别并指定**：勾选真正的名字后，自动建立演唱者、给这些行指定，并可以把名字从歌词里去掉。名字原本也会被当成歌词对齐，所以最好在对齐之前做（“音频与歌词”页也会提示）。

指定的是“谁唱哪几个字”，改歌词、改读音、合并或拆分行都会跟着保留；删掉一位演唱者时，后面的编号依次前移。导出的 ASS 里每位演唱者有自己的样式（KMain_1、KMain_2……），事件的“说话人”一栏是演唱者的名字，方便在其他软件里继续调整。

**开唱倒计时**：第一句前、以及长间奏（默认和上一句隔 6 秒以上）之后，行首上方会显示几个圆点（默认 3 个），最后几秒每秒消失一个，最后一个在这一句开始扫光时消失；这一句会在倒计时开始时出现（默认开唱前 3 秒），出现后一秒消失第一个点，中间不会停顿；等待时间不到 3 秒时均匀地更快消失。显示两三行时，带倒计时的这一句总在最上面一行，圆点不会盖住别的歌词。在样式“时间”里可以分别关掉第一句前 / 间奏后、调整算作间奏的停顿和圆点数。某一句要单独加上或去掉：在预览里选中这一行，把“倒计时”设为“显示”或“不显示”（旁边的“看倒计时”会跳到它显示的时刻）。

## 5. 常见问题

**更新到新版本。** 有新版本时，界面左下角（极简模式在右上角）会显示“有新版本”。关闭 MiliKara，双击离线版文件夹里的 `更新.bat`（macOS：`更新.command`，第一次需要右键 →“打开”）：它只下载有变化的部分（通常约 1 MB；旧版缺少的字体会一起补上），替换前先把原来的文件备份，新版本启动不了会自动恢复；再次运行可以选择“退回上一版”。新版本需要不同的依赖时，它会提示下载完整离线包。访问 GitHub 很慢时，从网盘下载 `MiliKara-版本-app.zip` 放进文件夹再运行，就不用联网。设置页可以关掉“检查新版本”。

**从旧版本（KiraKara）升级。** v1.1.0 起改名为 MiliKara，只是名字变了。旧的文件夹里没有更新程序：从 Releases 下载 `MiliKara-updater-windows.bat`（macOS 下载 `MiliKara-updater-macos.zip` 并解压），放进原来的文件夹双击，就会更新到新版本，并换上新的启动文件 `MiliKara.bat` / `MiliKara.command`；也可以直接下载新的离线包。以前的项目、任务、设置和字幕预设都会原样出现（它们保存在用户目录的 `.kara_align` 文件夹里，不在程序文件夹里）。从源码安装的，重新执行一次安装命令后用 `milikara` 命令（`kirakara` 仍然可用）。

**注音想用片假名或罗马音。** 极简模式在制作页第 4 步“字幕与视频”的“注音”里选（无 / 平假名 / 片假名 / 罗马音，还可以只标汉字）；详细模式在“卡拉OK字幕”的字幕样式 →“注音”里选。这是整首歌一起切换的。

**字幕感觉早了或晚了。** 先确认第一句的位置对不对（详细模式“首音校准”）。整体都偏一点的话，调整字幕样式“时间”里的“歌词提前显示”（默认 150 ms）。

**有几句对得不好。** 在“人工检查”的 **有问题** 标签页找到它们：读音不对就先改读音，再对这一行局部重跑；或者直接在波形上拖动单元的两端。常见的原因包括读音错误、和声或合唱、视频是剪短的版本等。标着 **置信度低** 的行是模型听到的发音和读音差得较多的地方，常见于英文、括号里的和声，试听一下就知道对不对。

**磁盘空间不够了。** 每首歌的项目里有视频、分离出的人声和伴奏、生成的视频，通常几百 MB。设置页的 **存储空间 → 查看和清理**（详细模式在左下角的 **存储空间**，首页“最近项目”右上角也有）列出每个项目占多大、分别是什么：
- 可以删掉整个项目，也可以只删导出的视频，或者只删人声分离的分轨（之后降低人声或重新对齐时要重新分离）。
- **缓存**（播放用的解码音频、波形、模型的识别结果）和 **残留文件**（已导入任务的上传副本、被替换的旧音频）可以放心清理。
- 删除项目会一起删掉它的缓存。模型不在这里清理。

**反馈问题。** 设置页“更新与反馈”里的 **复制诊断信息**（任务失败时任务下方也有）会复制一份报告：版本、系统、显卡、ffmpeg、主要设置和日志的最后部分，不含 API Key。完整日志在用户目录的 `.kara_align/logs/milikara.log`。

**生成视频慢 / 画质。** 设置页“输出视频”里的 **使用显卡编码** 默认打开：有可用的 NVIDIA / Intel / AMD 显卡编码器时用它（Mac 上只在烧录进原视频时用，纯色或图片背景时 CPU 更快），不可用或失败时自动改用 CPU。对画质不满意可以关掉。

**一句歌词太长。** 放不下的行会自动在空格或标点处（没有时在两个词之间）分成两半，像两行一样轮流显示，翻译仍是一整行；也可以在字幕样式“布局”里改成按 AI 注音时建议的位置换行，或者不换行。换行后仍放不下的行可以伸到离画面边缘 50 px 处，再放不下才缩小。歌曲信息始终显示在设定的角落，整段时间都在：太长的歌名会换行而不是被压扁；顶部的翻译伸到它那里时，它会变窄（多换几行）让开翻译。只有翻译几乎占满整个顶部、再窄也放不下时，才会等翻译消失后再出现，或移到翻译下面。

**歌词里的英文。** 逐个念出的大写字母（R O M A…）会按字母名读，一个字母一个单元；英文单词最好让 AI 按实际唱法写成假名。

**视频比歌词短（TV 版等）。** 时间在音频结束之后的歌词行不会对齐，也不会出现在字幕里，会有提示；其余行照常处理。

**模型在哪里，能离线用吗？** 第一次使用时，模型下载到程序目录的 `models/` 里（对齐模型约 1.2 GB，分离模型每个约 0.6–1 GB），之后不需要联网。要放到别处，设置环境变量 `KARA_ALIGN_MODELS`。

**想在手机或另一台电脑上访问。** 服务默认只接受本机访问。用 `milikara serve --host 0.0.0.0 --allow-host <本机局域网地址>` 启动后，再用那个地址访问。

**字体。** 字幕使用本机的字体；内置的“暖阳”样式用的是 macOS 的圆体（Hiragino Maru Gothic）。在其他系统上会自动换成可用的日文字体，也可以在样式里选择字体。
