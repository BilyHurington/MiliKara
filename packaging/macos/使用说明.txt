MiliKara（macOS · Apple 芯片）离线版  @VERSION@
==============================================

用一首歌和它的歌词，做出逐字扫光的日语卡拉OK视频。
项目主页和完整教程：https://github.com/BilyHurington/MiliKara

一、运行
1. 解压后，双击 MiliKara.command。
   第一次打开时 macOS 可能提示“无法验证开发者”：请在访达里右键点 MiliKara.command →“打开”→“打开”。
   （或者在“系统设置 → 隐私与安全性”底部点“仍要打开”。）以后直接双击即可。
2. 终端窗口里会显示启动信息，十几秒后浏览器自动打开 MiliKara。
3. 用完关闭那个终端窗口即可停止。

二、说明
- 需要：Apple 芯片的 Mac（M1 及以后），macOS 14.8.5（Sonoma 的最新更新）或更新版本，包括 macOS 15、26。
- 已经包含：Python 运行环境、全部依赖、ffmpeg（含 libass 字幕渲染）、中日文字体 Noto Sans CJK、彩色 emoji 字体 Noto Color Emoji，以及两个模型——
  对齐模型 NextFire/mms-300m-ForcedAligner-karaoke-ja-Latn 和人声分离模型 MelBand RoFormer。
  对齐、分离、生成视频都不需要联网。
- 需要联网的只有：从网易云 / QQ 音乐链接获取歌词，以及 AI 注音（选 Claude Code / Codex / API 时）。
  设置里换用其他分离模型时，会在第一次使用时下载。
- 设置、字幕预设和项目保存在你的用户目录 ~/.kara_align 里，删除或更新这个文件夹不会丢失它们。
- 整个文件夹可以放在任何位置；移动后照样双击运行。
- 命令行：在终端里运行 ./MiliKara.command --help。

三、更新
- 双击 更新.command：检查新版本，只下载有变化的部分（通常约 1 MB），不用重新下载整个离线包；
  模型、依赖和你的项目都保持不变。更新前请先关闭 MiliKara。
  第一次打开时同样需要在访达里右键点 更新.command →“打开”。
- 访问 GitHub 很慢时：从网盘下载程序更新包（MiliKara-版本-app.zip），放到这个文件夹里再双击 更新.command，
  会直接用它更新，不用联网。
- 新版本有问题时：再次双击 更新.command，选择“退回上一版”。
