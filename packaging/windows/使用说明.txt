MiliKara（Windows · @VARIANT_LABEL@）离线版  @VERSION@
==============================================

用一首歌和它的歌词，做出逐字扫光的日语卡拉OK视频。
项目主页和完整教程：https://github.com/BilyHurington/MiliKara

一、运行
1. 用 7-Zip（或 Bandizip、WinRAR）解压；分成多个分卷（.7z.001、.7z.002…）时，下载全部分卷后解压 .7z.001 即可。
   请解压到一个路径较短的文件夹，例如 D:\MiliKara。
2. 双击 MiliKara.bat。
   第一次运行时 Windows 可能弹出“Windows 已保护你的电脑”：点“更多信息”→“仍要运行”。
   防火墙询问时可以拒绝（MiliKara 只在本机使用，不需要局域网访问）。
3. 黑色窗口里会显示启动信息，十几秒后浏览器自动打开 MiliKara。
4. 用完关闭那个黑色窗口即可停止。

二、说明
- 需要：64 位 Windows 10 或 11。
@VARIANT_NOTE@
- 已经包含：Python 运行环境、全部依赖、ffmpeg（含 libass 字幕渲染）、中日文字体 Noto Sans CJK、彩色 emoji 字体 Noto Color Emoji，以及两个模型——
  对齐模型 NextFire/mms-300m-ForcedAligner-karaoke-ja-Latn 和人声分离模型 MelBand RoFormer。
  对齐、分离、生成视频都不需要联网。
- 需要联网的只有：从网易云 / QQ 音乐链接获取歌词，以及 AI 注音（选 Claude Code / Codex / API 时）。
  设置里换用其他分离模型时，会在第一次使用时下载。
- 设置、字幕预设和项目保存在你的用户目录 %USERPROFILE%\.kara_align 里，删除或更新这个文件夹不会丢失它们。
- 整个文件夹可以放在任何位置；移动后照样双击运行。
- 命令行：在这个文件夹里打开终端，运行 MiliKara.bat --help。

三、更新
- 双击 更新.bat：检查新版本，只下载有变化的部分（通常约 1 MB），不用重新下载整个离线包；
  模型、依赖和你的项目都保持不变。更新前请先关闭 MiliKara。
- 访问 GitHub 很慢时：从网盘下载程序更新包（MiliKara-版本-app.zip），放到这个文件夹里再双击 更新.bat，
  会直接用它更新，不用联网。
- 新版本有问题时：再次双击 更新.bat，选择“退回上一版”。
